# Hello World React App

React-приложение, созданное в рамках лабораторной работы по веб-программированию.

## Реализовано:
- ✅ Компонент `Button` (кнопка с разными стилями)
- ✅ Компонент `Container` (контейнер для контента)
- ✅ Компонент `Navigation` (панель навигации)
- ✅ Маршрутизация между страницами `Home` и `About`
- ✅ Кнопка с приветствием "Hello World! 🎉"

## Стек технологий:
- React
- React Router DOM
- Vite
